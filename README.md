# Cortex Codegen

**Project owner: Fibonera.**

Cortex is an in-repository AI software-engineering research platform. The
repository contains a transformer implementation, tokenizer and datasets,
training infrastructure, knowledge and memory components, MoE and virtual
parameter systems, evaluation tooling, planning and execution pipelines, and
sandbox/security controls.

## Verification status

Implementation, test execution, training, and benchmark promotion are tracked
as separate evidence states. A component's presence in the repository does
not imply that it has passed runtime qualification or that the model has
demonstrated the corresponding capability.

The 2B-class physical model is an architecture/configuration target; it has
not been trained to completion. The 500B virtual-parameter capacity is not a
claim that 500B parameters have been trained. See the stage verification
reports and benchmark artifacts for the recorded results and limitations.

## Repository status

The active Cortex implementation and its remediation work are maintained in
the Fibonera development branches and pull requests. The default branch may
not yet contain the complete implementation.

No Hugging Face Space deployment is configured by this repository workflow.
